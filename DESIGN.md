# Дизайн мастерской

Существующий стиль сохраняется: молочная бумага, ткань, винный акцент, тонкие разделители. Главный образ — письмо и авторская работа. Без ярких градиентов и декоративных эффектов поверх товаров.

Гибридный продукт: публичная витрина и документы — спокойная редакционная подача; оформление и админка — ясные действия и ошибки. Язык ru-RU, аудитория русскоязычная. Проект демонстрационный, реальные списания запрещены.

Канонический источник токенов — :root в src/app/globals.css (модель B). Значения выше зеркалят существующий CSS; компоненты используют var(--paper), var(--ink), var(--wine), var(--muted), var(--line), var(--linen), var(--white). Нормативная типографика — существующие --serif и --sans. Новые независимые палитры не создаются.

CookieNotice — немодальное уведомление без блокировки страницы и без согласия на аналитику. Запоминает прочтение; повторное открытие доступно из подвала. Для уведомления резервируется место, фокус не должен перекрываться; оно не перехватывает фокус при первом посещении.

PrivacyConsent — общий владелец отметки согласия во всех формах. По умолчанию false; ссылки открываются в новой вкладке, чтобы сохранить введённые данные. Принятие оферты — отдельная отметка только при оформлении. Ошибки показываются рядом, сервер отклоняет отсутствие согласия.

LegalDocument — общая структура для политики, согласия, условий тестовой оплаты и cookie: заголовок, редакция, демо-оговорка, содержание и секции. На телефоне одна колонка; документы доступны без отметки согласия.

Не изменять при этой задаче продуктовые сетки, каталог, деньги и статусы заказов. Не добавлять рекламу или аналитику. Cookie-сообщение не выдаёт соблюдение юридических требований за доказанный факт.
