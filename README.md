# Письма и звёзды

Портфолио-магазин авторских подарков, вдохновлённых миром Гарри Поттера. Уютная вымышленная мастерская с полным путём покупки и закрытой админкой для управления товарами.

**[Открыть магазин](https://letters-and-stars.vercel.app)** · [Описание для портфолио](docs/portfolio.md) 

![Главная страница магазина](docs/preview.webp)

## Дизайн

Тёплый молочный фон, винный акцент, Literata и Manrope, предметные композиции и много воздуха. Адаптивная вёрстка, управление с клавиатуры, видимый фокус и поддержка уменьшения движения. Сгенерированные изображения оптимизированы в WebP; шрифты хранятся локально. Источники и лицензии: [ASSETS.md](ASSETS.md).

## Функциональность

- Каталог с поиском, категориями, сортировкой по цене и фильтрами в URL.
- Страницы товаров с галереями, вариантами исполнения, количеством и наличием.
- Сохраняемая корзина с синхронизацией между вкладками.
- Оформление заказа: валидация, тарифы доставки, серверный расчёт суммы и резервирование остатков.
- Тестовая ЮKassa: защищённая форма провайдера, сверка статуса через API и HTTP-уведомления. Отдельно доступен локальный симулятор оплаты.
- Постоянное хранение снимков заказов и цен, защита доступа через HttpOnly cookie, защита повторных запросов и платёжных событий.
- Письма с составом заказа через Resend, постоянная очередь и защита от повторной отправки.
- Закрытая админка: товары, цены, остатки, фотографии, автоматические адреса страниц, скрытие товаров и просмотр заказов. Пароль хранится как scrypt-хеш.

После оплаты корзина удаляет только позиции оформленного заказа, сохраняя более поздние добавления.

## Технологии

| Область | Технологии |
| --- | --- |
| Интерфейс и сервер | Next.js 16 App Router, React 19, TypeScript, CSS |
| Облачная база | Supabase PostgreSQL, pg, транзакции |
| Локальная база | SQLite, better-sqlite3, Drizzle ORM |
| Изображения | Supabase Storage, Sharp, WebP |
| Платежи и письма | Тестовый API ЮKassa, Resend |
| Проверки | Node.js Test Runner, PGlite, Playwright |
| Размещение | Vercel; подготовлен альтернативный запуск через Docker |


Каталог редактируется через админку; src/data/catalog.ts содержит первоначальное наполнение, категории и тарифы. Локальная SQLite и облачная база независимы. Секреты, базы, загруженные фотографии пользователей и приватные проверочные файлы исключены из репозитория.

## Демонстрационный статус

Это неофициальный портфолио-проект: реальных покупок, списаний и доставки нет. Рабочие ключи оплаты код отклоняет. На Vercel включена тестовая ЮKassa, локальный симулятор остаётся отдельным режимом.

Отправка письма проверялась локально; доставка на настоящую почту после публикации пока не подтверждена. Полный публичный сценарий окончательной отмены и новой попытки также ещё не проверен; соответствующие изолированные автоматические тесты есть. Доступ к заказу привязан к браузеру оформления. Для настоящего магазина нужна отдельная подготовка.
