# Письма и звёзды

Авторский интернет-магазин подарков, вдохновлённых миром Гарри Поттера. Вымышленная мастерская объединяет блокноты, открытки, закладки, украшения и декор. Визуальное решение — тёплая палитра, винный акцент, выразительная типографика и спокойные предметные композиции.

Реализован полный путь покупателя: каталог с поиском и фильтрами, страница товара, сохраняемая корзина, оформление заказа и тестовая оплата через ЮKassa. Сервер рассчитывает суммы, резервирует остатки, хранит снимки заказов и проверяет платежи через API и уведомления. Закрытая админка позволяет управлять товарами, ценами, наличием и фотографиями. Для подтверждений заказа подключён Resend с постоянной очередью писем.

Стек: Next.js 16, React 19, TypeScript, CSS, Supabase PostgreSQL и Storage, Sharp, API ЮKassa, Resend. Для локального запуска — SQLite и Drizzle ORM. Проверки — Node.js Test Runner, PGlite и Playwright. Размещение — Vercel.

[Посмотреть проект](https://letters-and-stars.vercel.app)

Проект демонстрационный: используются только тестовые платежи, реальные покупки и доставка не выполняются. Ограничения и результаты проверок указаны в README.
