# Этап 4 — постоянные заказы и локальная демооплата

Реализован полный локальный путь: главная → каталог → товар → корзина → оформление → сохранённый заказ → выбор исхода демооплаты → фактический статус.

Сервер рассчитывает цены и доставку в копейках, валидирует контакты/адрес/согласия/варианты/количество, сохраняет снимок заказа в SQLite до оплаты. Транзакции защищают общие остатки вариантов, резервы и однократное списание при успехе. Резерв действует 30 минут. Повторная оплата остаётся в том же заказе.

Доступ: случайная cookie, её hash в базе, UUID заказа, no-store ответы, отдельная защита POST по Origin. API статуса не содержит контактов. При открытии чужого заказа показана оформленная 404 без состава; API возвращает 404. Next.js может отправить HTTP 200 для уже начатого потокового HTML с последующей 404, поэтому проверяется также отсутствие данных заказа.

Корзина хранит идентификаторы отдельных добавлений. Успех удаляет только захваченные в заказ добавления. Проверено сохранение более позднего количества того же SKU, других товаров, второй вкладки и повторного посещения результата.
