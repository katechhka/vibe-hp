# Опубликованный тестовый магазин

Магазин: https://letters-and-stars.vercel.app
Админка: https://letters-and-stars.vercel.app/admin

Размещение: Vercel, проект letters-and-stars. База: Supabase PostgreSQL, закрытая схема shop. Загружаемые фотографии: закрытый bucket product-images; сервер отдаёт разрешённые изображения через /media/.

PAYMENT_MODE=yookassa_test. Используются только тестовые ключи ЮKassa. Рабочие ключи код отклоняет. Реальные покупки и доставка не выполняются.

Данные локального магазина перенесены и сверены по всем полям. Пароль администратора сохранился; используйте свой последний установленный пароль. Старые сессии не переносились, поэтому требуется войти заново. Каталог опубликованного магазина меняйте в онлайн-админке: локальная SQLite и облачная база после переноса независимы.

## Повторная публикация

В папке проекта выполните npx vercel deploy --prod. Связь с проектом хранится локально в .vercel; секреты находятся в Environment Variables проекта Vercel и не загружаются вместе с исходниками. Настройка: [supabase.md](./supabase.md).

## Платежи и уведомления

APP_URL=https://letters-and-stars.vercel.app
Адрес HTTP-уведомлений: https://letters-and-stars.vercel.app/api/payments/yookassa/webhook
События: payment.succeeded, payment.canceled, payment.waiting_for_capture.

Сервер сверяет уведомления через API ЮKassa; адрес страницы результата не подтверждает оплату. Ключи и пароль базы находятся только на сервере. Пользователь сообщил, что уведомления в тестовом магазине настроены.

Для ручного теста используйте только карты из официальной документации: https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing . Успех: 5555 5555 5555 4444, дата из будущего, любой CVC. Отказ по недостатку средств: 5555 5555 5555 4600. Форма провайдера может разрешить другую карту в том же платеже, оставляя статус pending; простое закрытие формы также не означает окончательную отмену.

## Проверки и ограничения

Результаты публичных проверок: vercel-check-results.json. Проверены страницы на 360, 768 и 1440 px, оформление, серверная валидация, фотографии, отказ карты, подтверждённая API успешная тестовая оплата и запрет доступа из чужой сессии. Повторные уведомления не списывают остатки повторно.

В проверках использованы вымышленные контакты и недоставляемый адрес qa@example.invalid. Доставку письма на настоящую почту на опубликованном сайте пока не проверяли. Resend может ограничивать получателей, если отправитель не имеет подтверждённого домена. Неуспешная отправка письма не отменяет оплату; очередь сохраняется в базе.

Автоматические проверки создают тестовые заказы в онлайн-админке и уменьшают остатки при подтверждённой тестовой оплате. В них нет реальных контактных данных. Терминальные отмена и повторная попытка проверялись автоматическими тестами; полный публичный сценарий окончательной отмены ещё не подтверждён.

Локальный сетевой маршрут до PostgreSQL был нестабилен; опубликованный сервер успешно создаёт заказы и подтверждает платежи. Бесплатные планы имеют ограничения: доступность и тарифы проверяйте в панелях Vercel и Supabase. Перед любым настоящим приёмом денег требуется отдельная подготовка; этот проект остаётся тестовым.
